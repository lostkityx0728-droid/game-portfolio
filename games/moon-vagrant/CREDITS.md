# Moon Vagrant browser preview

Game concept, implementation and playtesting: Rong Guo.

This browser preview runs the existing GDevelop 5.6 exported game. It excludes the desktop executable, editable engine project, development paths, cloud project identity and four background music tracks without verified publication permission. Gameplay events remain the exported game events; omitted music calls use an original silent WAV. Larger original images were converted to WebP for loading size. The preview requires a keyboard and mouse.
